# Stack Frontend

## Core
- **React 19** + **Vite 8** (Rolldown)
- **React Router DOM 7**
- **TailwindCSS 3**
- **Axios**
- **React Hot Toast**

## Librerías clave
- `html5-qrcode` - Escaneo de código de barras con cámara/lector
- `jsbarcode` - Generación de código de barras Code128
- `jspdf` - Generación de PDF de etiquetas
- `qrcode` - Generación de QR para fichas públicas
- `lucide-react` - Iconos
- `recharts` - Gráficas
- `xlsx` - Exportación a Excel
